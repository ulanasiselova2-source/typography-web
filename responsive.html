Раздел 04

Адаптивная типографика

Текст должен оставаться удобным для чтения независимо от размера экрана устройства.

Что такое адаптивная типографика?

Адаптивная типографика предполагает изменение размеров и расположения текста в зависимости от ширины экрана. Один и тот же сайт должен удобно восприниматься на смартфоне, планшете и компьютере.

Для этого используются относительные единицы измерения, медиазапросы CSS и современные функции, например clamp().

Основные размеры экранов

01

Мобильные устройства

До 768 px

На небольшом экране текст должен занимать доступную ширину, а меню переходить в компактный формат.

02

Планшеты

От 768 px

Появляется больше пространства для текста, колонок и дополнительных информационных блоков.

03

Большие экраны

От 992 px

Можно использовать широкую сетку, боковые панели и более крупные элементы интерфейса.

Медиазапросы

Медиазапросы позволяют применять разные CSS-правила в зависимости от характеристик устройства. 

/* Мобильные устройства */
@media (max-width: 767px) {
    body {
        font-size: 16px;
    }
}

/* Планшеты */
@media (min-width: 768px) {
    body {
        font-size: 17px;
    }
}

/* Большие экраны */
@media (min-width: 992px) {
    body {
        font-size: 18px;
    }
}

Функция clamp()

Функция clamp() позволяет задать минимальное, предпочтительное и максимальное значение размера текста. Благодаря этому заголовок может плавно изменяться при изменении ширины экрана. 

h1 {
    font-size: clamp(2rem, 5vw, 4rem);
}

Пример

Размер этого заголовка может изменяться

Такой подход позволяет избежать слишком маленького или слишком большого текста на разных устройствах.

Правила адаптивного текста

  • Не допускайте слишком длинных строк.
  • Используйте комфортный размер основного текста.
  • Проверяйте расстояние между строками.
  • Заголовки должны сохранять визуальную иерархию.
  • Проверяйте страницу на разных размерах экрана.

Проверка адаптивности

В браузере Chrome можно открыть инструменты разработчика и включить режим эмуляции мобильных устройств. Это позволяет проверить, как изменяется текст при разных размерах экрана.
