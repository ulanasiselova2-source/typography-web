## О проекте

Учебный многостраничный сайт о типографике в веб-интерфейсах: как выбирать шрифты, строить визуальную иерархию, работать с адаптивной типографикой и цветом текста.

Сайт состоит из 9 связанных страниц:

| Страница | Файл | Описание |
|---|---|---|
| Главная | `index.html` | Обзор проекта и основных тем |
| Основы | `basics.html` | Базовые понятия веб-типографики |
| Шрифты | `fonts.html` | Виды шрифтов и их применение |
| Иерархия | `hierarchy.html` | Визуальная иерархия текста |
| Адаптивность | `responsive.html` | Адаптивная типографика |
| Цвет | `color.html` | Цвет и контраст текста |
| Практика | `practice.html` | Практические рекомендации, таблица с данными |
| Видео | `media.html` | Видеоматериалы по теме |
| О проекте | `about.html` | Информация о проекте и форма обратной связи |

Каждая страница включает шапку с адаптивной навигацией (бургер-меню на мобильных и планшетных экранах), боковую панель (`aside`), основной контент и подвал с контактами.

## Используемые технологии

- **HTML5** — семантическая разметка (`header`, `main`, `aside`, `footer` и т.д.)
- **CSS3** — кастомные стили поверх фреймворка (`css/style.css`)
- **[Bulma](https://bulma.io/)** — CSS-фреймворк
- **JavaScript (Vanilla JS)** — работа бургер-меню (`js/script.js`)
- **Responsive Web Design** — 3 контрольные точки:
  - до 768px — мобильные устройства
  - от 768px до 991px — планшеты
  - от 992px — десктоп

## Как запустить проект

### Вариант 1. Локально, без установки

1. Скачай или клонируй репозиторий:
   ```bash
   (https://ulanasiselova2-source.github.io/typography-web/index.html)
   ```
2. Перейди в папку проекта и открой файл `index.html` в браузере (Chrome, Firefox или Safari) — двойным кликом или через «Открыть файл».

Проект не требует сборки, сервера или установки зависимостей — это статичная вёрстка.

### Вариант 2. Через live-сервер (для удобной разработки)

Если установлено расширение Live Server (VS Code) или пакет `live-server`:
```bash
npx live-server
```
и открыть `index.html` из корня проекта.

### Вариант 3. Онлайн

Готовая версия сайта опубликована на GitHub Pages — см. ссылку в начале этого файла.
